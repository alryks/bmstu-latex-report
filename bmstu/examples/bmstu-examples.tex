\chapter{Подготовка отчёта}

\section{Структура и сборка}

Для нового отчёта возьмите \texttt{report.tex} из~корня шаблона.
Выберите одну титульную команду по~виду работы: \verb|\makereporttitle|, \verb|\makecourseworktitle|, \verb|\makeresearchtitle| или~\verb|\makethesistitle|.
В~исходнике этого руководства показаны их аргументы.
Данные для титульного листа берите из~задания.
Отсутствующие обязательные реквизиты уточняйте у~автора, а~необязательные аргументы можно оставить пустыми.

\textbf{Курсовые работы, курсовые проекты, ВКР и~аналогичные расчётно-пояснительные записки.}
Следуйте структуре \texttt{report.tex}.
Сохраните вводные разделы, в~том числе реферат, содержание, термины и~определения, перечень сокращений и~обозначений и~введение.
Основную часть оформляйте в~порядке шаблона: аналитический, конструкторский, технологический и~исследовательский разделы.
Далее идут заключение, список источников и~приложения при наличии.

\textbf{Отчёты о~НИР.}
Включайте реферат, содержание, термины и~определения, сокращения и~обозначения, введение, заключение, список источников и~приложения при наличии.
Названия и~состав глав основной части определяйте по~задачам исследования.
Аналитический, конструкторский, технологический и~исследовательский разделы из~шаблона для НИР сами по~себе не~обязательны.

\textbf{Лабораторные работы.}
По~умолчанию обязателен только титульный лист.
Остальную структуру подбирайте по~заданию и~указаниям преподавателя.
Например, вместо «Введения» можно сделать «Задание», а~далее оформить ход работы и~результаты.
Добавляйте содержание, реферат и~перечни, когда они нужны по~заданию.

Имена \texttt{.tex}-файлов можно менять по~содержанию.
После переименования обновите вызовы \verb|\include| и~\verb|\input|.
Если меняется заголовок ненумерованного раздела, обновите и~запись в~содержании, если она есть.
Например, в~лабораторной можно переименовать \texttt{10-introduction.tex} в~\texttt{10-task.tex} и~заменить заголовок на~«ЗАДАНИЕ».
Для работы с~заданной структурой переименование файла сохраняет требуемое название раздела в~PDF.

Основные главы удобно хранить в~отдельных \texttt{.tex}-файлах и~подключать через \verb|\include|.
Небольшие фрагменты без принудительного начала страницы подключайте через \verb|\input|.
Рисунки для \verb|\includeimage| храните в~\texttt{inc/img/}, исходники для \verb|\includelisting|~--- в~\texttt{inc/lst/}, библиографию~--- в~\texttt{biblio.bib}.

В~обычном тексте \texttt{.tex}-файлов соблюдайте правило «одно предложение~--- одна строка исходника».
Начинайте каждое новое предложение с~новой строки и~оставляйте длинные предложения целиком на~одной строке.
Пустую строку оставляйте между абзацами.
LaTeX сам переносит текст в~PDF, поэтому ручные переносы внутри предложения и~команда \verb|\\| для этого не~нужны.

Собирайте из~папки главного \texttt{.tex}-файла.
Для этого руководства используйте команду ниже.
Для \texttt{report.tex} из~корня шаблона задайте \texttt{TEXINPUTS=bmstu:} и~передайте \texttt{report.tex} вместо имени примера.
\texttt{latexmk} запускает повторные проходы и~Biber по~мере необходимости.

\begin{listing}{bash}{build-guide}{Сборка руководства из каталога examples}
TEXINPUTS=..: latexmk -lualatex bmstu-examples.tex
\end{listing}

После правок пересоберите PDF.
Проверьте предупреждения о~потерянных и~повторных метках, номера страниц в~содержании, библиографию и~места разрыва таблиц.
Сверьте также, что подписи и~формулы целиком помещаются между полями.

\section{Вводные разделы}

Для реферата используйте окружение \texttt{essay}.
По~ГОСТ~7.32-2017, пп.~5.3 и~6.12, реферат отчёта о~НИР включает сведения об~объёме, перечень из~5--15 ключевых слов и~текст.
Ключевые слова дают в~именительном падеже прописными буквами, через запятую и~без точки в~конце.
В~тексте последовательно указывают объект, цель, методы, результаты и~применение.
Сведения, которых в~работе нет, пропускают.
После сборки сверяйте автоматические счётчики реферата с~фактическим содержимым.

Содержание выводит \verb|\maketableofcontents|.
Ненумерованные введение и~заключение добавляйте в~содержание явно через \verb|\addcontentsline|.
Для реферата, определений, сокращений и~библиографии это уже делают команды класса.
ГОСТ требует, чтобы названия в~содержании соответствовали заголовкам, а~номера страниц были справа и~соединялись с~названиями отточием (пп.~5.4 и~6.13).

В~окружениях \texttt{definitions} и~\texttt{abbreviations} используйте \verb|\definition{термин}{пояснение}|.
Перечисляйте только обозначения и~термины из~самой работы.
Упорядочивайте записи по~алфавиту, разделяйте название и~пояснение тире, оставляйте строки без конечного знака препинания (пп.~6.14 и~6.15).

\section{Формулы}

Для отдельной формулы используйте \texttt{equation}, для нескольких строк с~одним номером~--- \texttt{aligned} внутри \texttt{equation}.
Класс нумерует формулы сквозным счётом по всему документу.
Ссылку на~номер оформляйте через \verb|\eqref|.
Например, число сочетаний вычисляется по~формуле~\eqref{eq:combinations}.

\begin{equation}\label{eq:combinations}
    \binom{n}{k} = \frac{n!}{k!(n-k)!},
\end{equation}

где $n$~--- число элементов множества,\\
$k$~--- число выбираемых элементов.

По~п.~6.8 поясняйте новые обозначения сразу под формулой в~порядке их появления.
Каждое пояснение начинайте с~новой строки.
После «где» двоеточие не~ставят.
Для системы условий используйте \texttt{cases}, как в~формуле~\eqref{eq:threshold}.

\begin{equation}\label{eq:threshold}
    f(x)=
    \begin{cases}
        0, & x < 0,\\
        x, & x \geq 0.
    \end{cases}
\end{equation}

\begin{equation}\label{eq:aligned-example}
    \begin{aligned}
        S_2 &= 1 + 2,\\
        S_3 &= S_2 + 3.
    \end{aligned}
\end{equation}

В~формуле~\eqref{eq:aligned-example} символ \verb|&| задаёт выравнивание по~знаку равенства.
Для ненумерованной выкладки используйте \texttt{equation*}, для матрицы в~такой выкладке~--- \texttt{pmatrix}.

\section{Листинги}

Для файла используйте \verb|\includelisting| и~передавайте имя внутри \texttt{inc/lst/}.
Расширение можно опустить, если оно определяется однозначно.
Метка создаётся из~имени файла без расширения.
Если один файл нужно вставить несколькими диапазонами, передайте разным вызовам разные суффиксы в~последнем необязательном аргументе.
Для кода прямо в~\texttt{.tex} задайте язык, имя метки и~подпись в~окружении \texttt{listing}.

\includelisting[firstline=3,lastline=7]{c}{greeting}

print_greeting("Ada");

\section{Таблицы}

В~таблице~\ref{tab:autofit} приведены тестовые случаи с~короткими значениями и~описаниями разной длины.

Для таблиц используйте \texttt{longtblr}.
Класс задаёт полную ширину, сетку и~подписи слева.
В~параметрах таблицы укажите подпись, метку и~состав столбцов.
Параметр \texttt{rowhead=2} повторяет две строки шапки, а~\verb|\SetCell| с~параметром \texttt{r} или~\texttt{c} объединяет ячейки по~вертикали или~горизонтали.
Параметр \texttt{m} центрирует содержимое ячейки по~высоте.

По~п.~6.6 на~каждую таблицу нужна ссылка.
Название ставят слева над первой частью с~прописной буквы и~без точки.
Для продолжения указывают тот же номер таблицы.
Заголовки граф центрируют и~пишут без точки в~конце.
Заголовки строк выравнивают слева.
Разрыв страницы возможен между строками, поэтому проверяйте высокие ячейки и~группы объединённых строк в~PDF.

Для нескольких сносок объявите пояснения через \verb|note{1}={текст}|, \verb|note{2}={текст}| и~так далее.
Номера задаются вручную.
Вставляйте метку через \verb|\TblrNote{1}| в~каждой ячейке, к~которой относится первое пояснение.
Текст сноски под таблицей появится один раз.

\section{Списки и источники}

В~перечислении, которое продолжает вводную фразу, начинайте пункты со~строчной буквы.
По~ГОСТ~7.32-2017, п.~6.4.6, простой список разделяют запятыми, сложный~--- точками с~запятой.
Последний пункт завершает предложение точкой.
Для перечня по~умолчанию ставят тире.
Если на~пункт нужно сослаться, используют строчные русские буквы со~скобкой, пропуская ё, з, й, о, ч, ъ, ы, ь.
Для известного числа пунктов допускаются цифры со~скобкой.
Класс задаёт маркеры, а~регистр и~знаки препинания нужно задать в~тексте.

Комплект отчёта включает:
\begin{itemize}[labelindent=\parindent,leftmargin=*]
    \item исходник,
    \item данные,
    \item собранный PDF.
\end{itemize}

После правок выполните три проверки:
\begin{enumerate}[labelindent=\parindent,leftmargin=*]
    \item пересоберите PDF и~проверьте журнал сборки;
    \item откройте изменённые страницы и~сверьте разбиение таблиц;
    \item проверьте номера элементов и~переходы по~ссылкам.
\end{enumerate}

Если в~тексте нужны ссылки на~отдельные пункты, можно выделить два условия готовности:
\begin{enumerate}[label=\asbuk*),labelindent=\parindent,leftmargin=*]
    \item все исходники и~используемые данные доступны;
    \item PDF успешно собирается и~доступен для проверки.
\end{enumerate}

Условие~б) проверяют после выполнения условия~а).

\begin{samepage}
Вложенные списки оформляйте только там, где у~пункта действительно есть подпункты.
Например, проверка отчёта включает:
\begin{enumerate}
    \item сборку документа;
    \item просмотр страниц с~результатами, включая:
    \begin{itemize}
        \item подписи рисунков,
        \item повтор шапки таблицы.
    \end{itemize}
\end{enumerate}
\end{samepage}

Ключ записи в~файле \texttt{biblio.bib} передаётся команде \verb|\cite|.
Например, описание пакета для оформления листингов приведено в~документации~\cite{minted}.

Список выводите через \verb|\makebibliography|.
По~пп.~6.9 и~6.16 ссылки оформляют номерами в~квадратных скобках, а~источники приводят в~порядке первого цитирования.
Заполняйте карточки только по~проверенным данным источника и~проверяйте после сборки, что все ключи разрешились.
