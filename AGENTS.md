# Работа с шаблоном BMSTU

Перед созданием или изменением отчёта прочитай [гайд](bmstu/examples/bmstu-examples.tex) и следуй описанным в нём правилам оформления, структуре для нужного вида работы и примерам использования класса `bmstu`.

Для нового отчёта используй [шаблон](report.tex) как основу. В обычном тексте пиши одно предложение на строку исходника. После правок пересобери PDF по инструкции из гайда и проверь результат.
