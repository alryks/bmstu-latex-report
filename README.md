# bmstu-latex-report

Шаблон LaTeX для лабораторных, курсовых, НИР и ВКР в МГТУ им. Н. Э. Баумана. В комплекте заготовка отчёта и гайд с рабочими примерами оформления.

## Начало работы

1. Возьмите за основу [report.tex](report.tex) и заполните [титульный лист](01-title.tex).
2. Выберите структуру по виду работы. Для курсовой и ВКР используйте разделы заготовки, для НИР подберите главы по задачам исследования, для лабораторной следуйте заданию.
3. Храните изображения в `inc/img/`, исходники для листингов в `inc/lst/`, а записи библиографии в [biblio.bib](biblio.bib).
4. Соберите PDF и проверьте содержание, ссылки и переносы между страницами.

## Сборка

Нужны LuaLaTeX, `latexmk`, Biber и подсветка `minted` с Pygments. Класс использует шрифты Times New Roman, Courier New и XITS Math.

Сборка отчёта из корня репозитория:

```sh
TEXINPUTS=.:./bmstu: latexmk -lualatex -shell-escape -auxdir=build \
  -interaction=nonstopmode -file-line-error report.tex
```

Сборка гайда:

```sh
cd bmstu/examples
TEXINPUTS=.:..: latexmk -lualatex -shell-escape -auxdir=build \
  -interaction=nonstopmode -file-line-error bmstu-examples.tex
```

`latexmk` запускает Biber и повторяет проходы LuaLaTeX по мере необходимости. Промежуточные файлы попадают в `build/`, а PDF сохраняется рядом с исходником. Команды используют обычный `PATH`.

## Что есть в гайде

- Титульные листы, реферат, содержание, термины, определения, обозначения и сокращения.
- Многостраничные таблицы и листинги с подписями продолжения, сноски к тексту и таблицам.
- Составные рисунки, чёрно-белые графики, альбомные страницы и вставка PDF в приложения.
- Примеры оформления по ГОСТ 7.32-2017 и правила подготовки исходника, включая одно предложение на строку.
